# CS Wiki

A static, multi-page computer science learning site. It uses plain HTML, CSS and JavaScript and can be hosted on GitHub Pages.

## Pages

- `index.html` — Home and featured articles
- `articles.html` — Searchable article library, bookmarks and locally saved custom articles
- `labs.html` — Binary, sorting and Caesar cipher interactive labs
- `about.html` — About the project

## Publish on GitHub Pages

Keep all four HTML files at the repository root, along with the `css` and `js` folders. Commit and push the files to the branch and directory configured in the repository's Pages settings. The site uses relative links and needs no build step.

Article bookmarks, theme preference and custom articles are saved in each visitor's browser using local storage.
